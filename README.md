# Daily Rhythm

Did it happen today?

A small record
for one of life's ordinary rhythms.

When it happens,
record how you feel.

How much?
How satisfied?

Nothing complicated.

Just a small note
about today's rhythm.

Some days are ordinary.
Some days are different.

The records quietly gather,
one day after another.

Daily Rhythm is a small app
for keeping track of your daily rhythm.

# でた？

今日、
でた？

毎日の小さなリズムを
記録するためのアプリです。

でたら、
今日の状態を記録する。

すっきりした？
それとも、
なんとなくすっきりしない？

その日の「すっきり度」を
残しておくことができます。

難しいことはしません。

ただ、
今日の小さな出来事をひとつ記録する。

普通の日もある。

いつもと違う日もある。

そんな記録が、
少しずつ積み重なっていく。

「でた？」は、
毎日の排便を記録する
小さなアプリです。
